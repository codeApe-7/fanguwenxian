# 《凡骨问仙》终端文字冒险游戏

一个凡人，从山村走出，测灵根、拜宗门、炼气筑基、结丹化神，历经机缘与劫难，
在红颜知己的相伴下，最终渡劫飞升……

TypeScript 编写，**核心逻辑与 UI 分离**，当前跑在终端，已预留网页迁移路径。

## 快速开始

```bash
npm install        # 安装开发依赖（typescript / @types/node / tsx）
npm run dev        # 开发模式直接运行（tsx）
# 或
npm run build      # 编译到 dist/
npm start          # 运行编译产物
npm run playtest   # 自动通关一局（文案 QA 用，可跟 1-4 指定剧本）
```

## 玩法

- **开局三选**：命运剧本（4 种，各带贯穿全程的专属主线）→ 觅长生式天赋点加点（出身/资质/灵根/体质/经历）→ 宗门（10 大门派，剑/道/佛/魔/丹/器/符/阵/双修/散修全覆盖）。
- **世界纪年**：玄启纪元，世界大事挂在绝对年份上——青崖英杰会（5 年一届，限筑基以下）、四海拍卖大会（10 年）、甲子灵潮（60 年）、玄阴魔乱/沉星海眼/天门虚影等一次性大事，**过窗即永久错过**，状态栏常驻「下一大事」提示。
- **主线剧情**：4 剧本共 53 个剧情节点铺满炼气→渡劫九大境界；触发看年龄窗/境界窗/前置 flag；抉择写 flag、几百年后仍有回响；**冲太快或走太慢都会错过内容**（配错过反馈）；渡劫期按一生抉择收束出不同终章。
- **传音投递**：红颜家书与求援、宗门嘉勉、亡命暗信、江湖战书……条件满足后延迟送达，剧情主动找上门。
- **修炼养成**：闭关（1/3/5/10 年）→ 突破小/大境界；功法 51 门（凡/灵/仙三品）、熟练度四阶、残篇参悟；丹毒系统（深了会触发走火剧情）。
- **宗门系统**：任务（三层文案+冷却+境界窗，**失败扣贡献**）/捐献 → 晋升职阶 → 宗门大比（按纪年 3 年一届）→ 挑战宗主 → 宗门战争；叛宗有追杀（也有专属剧情与求和路）。
- **四艺副业**：炼丹/炼器/阵法/符箓，拜师、奇遇或拜入对应宗门解锁。
- **红颜系统**：主线专属女主 + 游历邂逅；**八种性格各有整套对白**（交谈/论道/赠礼/重逢/来信全场景查表），好感 40/70 各有一段专属小剧情，好感≥80 结为道侣（双修/护关/共渡天劫）。
- **人生大事记**：机缘、抉择、错过、突破全程自动立传；结局（飞升/殒身/寿尽）输出整部年表，飞升成功率与结语按一生 flag 结算。

## 架构：如何迁移到网页

核心逻辑（`src/core/`、`src/content*`、`src/types.ts`）**不依赖终端**，只依赖 `GameIO` 接口。
迁移网页时只需替换三个适配层，其余代码一行不改：

| 适配层 | 终端实现 | 网页替换 |
| --- | --- | --- |
| I/O | `terminal.ts`（readline） | 写一个 `WebIO`（DOM 按钮/输入框）实现 `GameIO` |
| 颜色 | `colors.ts`（ANSI 转义） | 让 `c()` 返回 HTML `<span>` 或纯文本 |
| 存档 | `store.ts`（fs 文件） | 换成 `localStorage` |
