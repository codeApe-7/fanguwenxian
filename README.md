# 《凡骨问仙》终端文字冒险游戏

一个凡人，从山村走出，测灵根、拜宗门、炼气筑基、结丹化神，历经机缘与劫难，
在红颜知己的相伴下，最终渡劫飞升……

TypeScript 编写，**核心逻辑与 UI 分离**，当前跑在终端，已预留网页迁移路径。

## 快速开始

```bash
npm install        # 安装开发依赖（typescript / @types/node / tsx）
npm run dev        # 开发模式直接运行（tsx）
# 或
npm run build      # 编译到 dist/
npm start          # 运行编译产物
```

## 玩法

- **开局三选**：命运剧本（4 种，各带专属主线事件链）→ 剧本专属出身（16 种）→ 宗门（10 大门派，剑/道/佛/魔/丹/器/符/阵/双修/散修全覆盖）。
- **修炼养成**：测灵根（可重测）→ 闭关（自选 1/3/5/10 年，也可参悟功法/残篇）→ 突破小境界/大境界。
- **功法体系**：51 门功法（凡品/灵品/仙品三阶），熟练度四阶（入门→小成→大成→圆满），每门附带神通（战斗中施展），残篇集齐可参悟补全（仙品仅此途径）。
- **宗门系统**：任务/捐献攒贡献 → 晋升职阶（外门→内门→真传→长老）→ 宗门大比 → 挑战宗主（年俸+宝库免单+宣战权）→ 宗门战争；叛宗有追杀惩罚。
- **四艺副业**：炼丹/炼器/阵法/符箓，需拜师、奇遇或拜入对应宗门解锁。
- **丹毒**：服修为丹累积丹毒（降低修炼/突破），每年自然消解，净元丹可清。
- **战斗冒险**：游历遭遇强敌，回合制战斗，可催动法宝、施展神通、服用疗伤丹、祭出符箓、逃跑。
- **女主系统**：主线剧情化邂逅专属女主 + 游历随机邂逅，性格影响好感获取，好感≥80 结为道侣（双修加速修炼），可共渡天劫达成「神仙眷侣」结局。
- **结局**：渡劫飞升（或与道侣携手飞升），或寿元耗尽/渡劫失败。

## 项目结构

```
src/
  index.ts          入口：装配终端 IO 与引擎
  io.ts             GameIO 接口（核心逻辑只依赖这个抽象）
  terminal.ts       终端版 GameIO（Node readline + ANSI）
  colors.ts         ANSI 颜色（渲染层）
  store.ts          存档持久化（Node 文件系统）
  types.ts          核心类型与状态定义
  content.ts        静态游戏数据 + 属性推导
  core/             纯逻辑层（不依赖终端）
    rng.ts          随机工具
    character.ts    角色生成、测灵根
    cultivate.ts    修炼、突破、飞升、服用丹药、残篇参悟
    combat.ts       战斗（法宝/符箓/神通）
    explore.ts      游历、随机事件调度
    events.ts       游历事件表（59+ 随机事件）
    market.ts       坊市
    crafts.ts       四艺副业（炼丹/炼器/阵法/符箓）
    sect.ts         宗门系统（任务/贡献/职阶/大比/宗主/战争/叛宗）
    romance.ts      女主/道侣
    storyline.ts    剧本专属主线事件链
    engine.ts       主循环、菜单、编排
```

## 架构：如何迁移到网页

核心逻辑（`src/core/`、`src/types.ts`、`src/content.ts`）**不依赖终端**，只依赖 `GameIO` 接口。
迁移网页时只需替换三个适配层，其余代码一行不改：

| 适配层 | 终端实现 | 网页替换 |
| --- | --- | --- |
| I/O | `terminal.ts`（readline） | 写一个 `WebIO`（DOM 按钮/输入框）实现 `GameIO` |
| 颜色 | `colors.ts`（ANSI 转义） | 让 `c()` 返回 HTML `<span>` 或纯文本 |
| 存档 | `store.ts`（fs 文件） | 换成 `localStorage` |
