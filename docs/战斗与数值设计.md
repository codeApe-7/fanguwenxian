# 《凡骨问仙》战斗与数值设计

> 0.7 版战斗层与数值层重做的设计说明。
> 核心思路：**数值要有压制，战斗要有轮换，境界要有新机制**——
> 曲线走指数（越级如天堑），战斗靠灵气与后继无力逼你换招，
> 每个大境界加的是一层新机制，不是一串更大的数字。
>
> 剧情/调度层见 [剧情引擎与文案设计.md](剧情引擎与文案设计.md)。

---

## 1. 诊断：旧版（≤0.6.x）的六个病灶

| 症状 | 病根 |
| --- | --- |
| 元婴打化神只差四成，毫无「修为压制」 | 属性全线性：`攻击 = 8 + 绝对境界×5` |
| 同境界基本必败，一局 200 年只赢 2~3 场 | 玩家伤害 ×0.6，敌人防御却全额减免，净伤约为对方一半 |
| 松纹剑 +5 攻在炼气是天、在化神是噪声 | 装备走定值加成，与指数无关的量纲 |
| 疗伤丹恒回 40 血，后期形同虚设 | 消耗品同上 |
| 战斗＝「选 1 施法」重复到死 | 神通六种硬编码类型、一式一效果、每战限次、无消耗无成长 |
| 后 170 年只剩「闭关→突破」 | 九个大境界除 `difficulty` 外没有任何新机制 |
| 两百年积累兑现为 `chance(0.7)` | 渡劫是一次掷骰，不是一场战斗 |

## 2. 成长曲线

### 2.1 战力基数：指数压制

```ts
// content.ts
export const REALM_STEP = 2.2;   // 大境界之间
export const STAGE_STEP = 1.18;  // 境界内每小阶
export function powerOf(realmIdx, stageIdx) {
  return Math.pow(REALM_STEP, realmIdx) * Math.pow(STAGE_STEP, stageIdx);
}
export const BASE_STATS = { hp: 48, atk: 12, def: 4, spd: 4, sense: 4 };
```

一切气血/攻击/防御都是 `基础值 × powerOf() × (1 + 百分比加成)`。

| 境界 | 气血 | 攻击 | 防御 |
| --- | --- | --- | --- |
| 炼气初期 | 48 | 12 | 4 |
| 炼气大圆满 | 79 | 20 | 7 |
| 筑基初期 | 106 | 26 | 9 |
| 结丹初期 | 232 | 58 | 19 |
| 元婴初期 | 511 | 128 | 43 |
| 化神初期 | 1124 | 281 | 94 |
| 炼虚初期 | 2474 | 618 | 206 |
| 合体初期 | 5442 | 1361 | 454 |
| 大乘初期 | 11973 | 2993 | 998 |
| 渡劫大圆满 | 43278 | 10820 | 3607 |

- **越一个大境界 = 对方各项 2.2 倍**：实测胜率 <5%，「修为压制」四个字第一次有了数值形态。
- **境界内 ±1 小阶 = 1.18 倍**：同境界之间有操作空间，法宝、神通、丹药能翻盘。
- **气血 ≈ 4 倍攻击**：同境界对拼约 9~10 回合见分晓，用得好神通与丹药则 6~7 回合。

### 2.2 一切加成改百分比

| 项 | 旧 | 新 |
| --- | --- | --- |
| 法宝 | `atk: 90`（定值） | `atkPct: 0.75` + `tier` 品阶（缴获比高低用它） |
| 功法 | `atk/def/hp`（定值） | `atkPct/defPct/hpPct` + `spd/sense`（定值，见 2.3） |
| 阵法 | `atk: 15` | `atkPct: 0.25` |
| 疗伤丹 | 回 40 血 | 回 **25% 气血** |
| 烈焰符 | 20 伤害 | **120% 攻击**的伤害 |

法宝扩到 10 件铺满九境；菜单同时显示百分比与当前折算值。

### 2.3 两条新属性：遁速与神识

指数曲线下**按差值使用的属性不能跟着指数膨胀**，故这两条走线性小数（4 → 22）：

- **遁速** `playerSpeed`：先手判定、闪避基础、**逃跑成功率**（速度差检定，不再掷骰）。
- **神识** `playerSense`：命中与破隐；**战前预判**——神识不及对手时，面板上敌人的五行与灵气显示为「？」。

### 2.4 小境界自动晋升

初期→中期→后期→大圆满**没有决策含量**，旧版却要玩家回主菜单按一次「突破」再掷一次骰子，一次十年闭关被打断三回。

- 修为满 100 且未到大圆满 → **自动晋升，不掷骰、不弹菜单**，溢出的修为结转进下一小阶（一次长闭关可连跨两三阶），心境 +1、悟道点 +1。
- **只有大圆满 → 下一个大境界**才是手动的：主菜单第 7 项「冲击大境界瓶颈」，未到大圆满时置灰；仍需突破丹、仍会失败、仍有走火入魔。
- 落点：`autoAdvance()` 在闭关每年、服丹后、`yearEnd` 各调一次（末者兜底，剧情/事件给的修为也算数）。

### 2.5 心境七档

心境 0~100 映射七档名（心猿意马 / 神静气安 / 古井不波 / 六情沉寂 / 看破红尘 / 超然物外 / 物我合一），
既是称谓，也是剧情门槛，更是**渡劫心魔劫时挡在你身前的那层护罩**（每档 8% 气血）。

## 3. 五行

```ts
export const SHENG = { 木:'火', 火:'土', 土:'金', 金:'水', 水:'木' };  // 相生
export const KE    = { 木:'土', 土:'水', 水:'火', 火:'金', 金:'木' };  // 相克
```

灵根不再是一个档位，而是**五个数值**：`Player.roots: Record<Element, number>`。
灵根档位决定「占几系、主系多深」——天灵根一柱擎天（95），五灵根五处平庸（34）。
创角时选「本命五行」，副属性排布开局摇一次即定。

三条乘区，全部作用在神通伤害上：

| 乘区 | 条件 | 倍率 |
| --- | --- | --- |
| **亲和** | 施展本命属性的神通 | ×(1 + 灵根值/200)，最高 ×1.475 |
| **连击（相生）** | 上一式的属性生本式属性 | ×1.25 |
| **相克** | 本式属性克敌方属性 | ×1.3 |
| **被克** | 敌方属性克本式属性 | ×0.8 |

三者相乘最高可达 ×2.4——**轮换神通本身就是最优解**，而不是找到一招无脑重复。

## 4. 神通（`content/spells.ts`，71 式）

### 4.1 一式 = 若干效果的组合

```ts
export interface SpellDef {
  name: string;
  element: Element | '无';   // 无属性＝身法/神魂/遁术，不吃相生相克
  tier: 1 | 2 | 3 | 4;       // 术 / 法 / 神通 / 仙法
  cost: number;              // 灵气消耗，★五级恒定
  effects: SpellEffect[];    // ★ 一式可多效果
  desc: string;              // 菜单一行功效
  flavor: string;            // ★ 施展时的画面
  price?: number; sect?: string;
}
```

17 种效果：`dmg / dot / heal / regen / shield / drain / buffAtk / weaken / vuln / guard / thorn / dodge / stun / qi / sap / escape / cleanse`。
于是「造成伤害 + 附三层灼蚀 + 令对方两回合易伤」只是填三条 effects，不用写代码分支。

**`flavor` 是这套设计的重点**：文字游戏没有画面，一句话就是画面，施展时打在战报上。

> 你反手一引，方圆百丈的剑气尽数立起——像一片倒悬的森林，然后落下。　—— 万剑归宗
>
> 藤上的倒刺扎进去就断在肉里，断口处渗出的汁水，是不肯干的。　—— 蚀骨毒藤

### 4.2 灵气：让普通攻击有存在意义

- `maxQi = 8 + ⌊绝对境界/3⌋`（8~19，以气入道 +6），起手 3 点，**每回合自然只回 1 点**。
- 神通耗气 0~6；**普通攻击额外聚气 +2**——普攻从此是资源引擎，不再是纯兜底。
- 敌方也有灵气：攒够 4 点才放绝技，所以「滞气」（`sap`）打的是它的节奏，不是血条。

### 4.3 三条铁律

1. **消耗恒定**：`SpellDef` 只有一个 `cost` 字段，五级共用——成长的意义是「把少数几式练厚」。
2. **威力递增**：`SPELL_LV_MULT = [1, 1.3, 1.7, 2.3, 3.2]`，增幅 ×1.30→×1.39，**最后一级最值钱**。
3. **后继无力**：连发同一式 `×[1, 0.6, 0.36, 0.2, 0.1]`，换招即复原。神通菜单实时显示当前倍率与「连击/克」提示。
4. **续航另走一条平缓曲线**：`SPELL_LV_SUSTAIN = [1, 1.1, 1.2, 1.3, 1.4]`。
   伤害按攻击的百分比结算，吃满 ×3.2 只是「一击更重」；疗伤/护罩/生机却按**自身气血的百分比**结算，
   同样乘 3.2 就意味着一式满级疗伤恢复 192% 气血——**任何疗伤式点满都等于「回满血」**，续航从此不设上限。
   续航也不吃五行相克：「火克金」是打对方用的，与你给自己疗伤无关。

### 4.4 悟道点：点不满，才叫取舍

`Player.insight`：小境界晋升 +1、大境界突破 +3 → 全程约 55 点；
升满一式需 2+4+7+12 = **25 点**。一周目只够点厚一两式。
入口：闭关 → 参悟神通。

### 4.5 获取渠道

功法附带（沿用）· 坊市「神通玉简」（灵石）· 宗门法堂（贡献，含**本宗不传之秘**）· 战利品掉玉简（只从「人」身上）· 化神入道赠一式仙法。
另外，**人人开局自带本命五行的入门一式**——否则炼气期的战斗只剩下反复戳「普通攻击」。

## 5. 战斗引擎（`core/combat.ts`）

### 5.1 伤害公式：比例减伤

```ts
dmg = round(atk * coef * atk / (atk + def))
```

量纲无关——在炼气期和渡劫期同样成立，这是指数曲线下唯一站得住的减伤模型。
普攻 `coef = 0.62`；神通按 `effects[].value`（攻击的百分比），再乘五行三乘区 × 后继无力 × 神通等级 × 入道加成。

### 5.2 战斗类型与规则开关

战斗是有类型的场合。`FightKind` 预设一组规则，调用点只写场合名：

| 场合 | 规则 |
| --- | --- |
| `普通` | 无特殊 |
| `擂台` | 败不至死、30 回合上限、到点按剩余血量比例判胜 |
| `切磋` | 败不至死、24 回合上限、按比例判胜 |
| `生死斗` | 无路可退 |
| `心魔` | 无路可退 + **禁丹药法器** |
| `天劫` | 无路可退 + 禁丹药法器 + 9 回合上限 + **到点算撑住了** |

可单独覆盖的开关：`noEscape / noItems / noDeath / roundLimit / onTimeout / preShield / startHpPct`。
**宗门大比与青崖英杰会显式加 `noItems`**——执法长老当众宣台规：登台者尽解丹药法器，比的是修为与神通，不是谁家底厚。

另有 `kind: FoeKind`（妖兽/修士/魔修/天骄/同门，决定取名池**与属性偏移**）、`foe`（指名道姓）、
`element`（指定五行）、`carry`（连战气血延续）、`enemy`（直接给一个对手，心魔与天劫用）。

### 5.3 敌人：和你用同一套语汇

敌人不是一个「血量 + 攻击」的靶子。它有**牌组、灵气、五行灵根**，一样吃后继无力与相生相克，
一样要攒灵气才放得出绝技。它和你唯一的区别是：**选哪一式由 AI 权重表决定，而不是由你按键。**

**牌组（`Enemy.deck`）**——「会几招」本身就是难度分层，而不是把血条调高：

| | 牌组大小 | 品阶上限 | 选材偏好 |
| --- | --- | --- | --- |
| 妖兽 | 境界档 −1（1~5 式） | 随境界 | 只有本能：不会疗伤、不会护罩、不会遁法 |
| 修士 / 同门 | 境界档（2~6 式） | 随境界 | 不挑 |
| 魔修 | 境界档 | 随境界 | 偏吸血与毒 |
| 天骄 | 境界档 +1（3~6 式） | 随境界 | 一整套，什么都会 |

七成本命属性、三成杂学：既有流派感，又不至于被一种属性克死。品阶上限随境界抬（炼气期的妖兽不会仙法）。

**选招（`chooseFoeSpell`）**——不是决策树，是**加权抽样**：每一式按「意图 × 局势」打权重，再按权重随机抽。
权重语汇分三档：**0 ＝ 绝不用**，几十 ＝ 兜底，几百 ＝ 这就是时候。

| 意图 | 条件 | 权重 |
| --- | --- | --- |
| 疗伤 | 自身气血 <35% | 900；<60% 给 90；血厚时 **0**——满血绝不吃药 |
| 净化 | 自身带灼蚀/易伤 | 320 |
| 护罩 / 减伤 | 气血 <75% 且身上没罩 | 240，否则 25 |
| 定身 | **对手灵气 ≥六成**（要放大招了） | 420，否则 70 |
| 滞气 | 对手灵气 ≥4 | 380，否则 25 |
| 战意 | 尚未叠过 | 300，叠过 **0** |
| 削弱 / 易伤 | 尚未挂上 | 240 / 260，挂过则 15 |
| 输出 | — | 60 + 伤害倍率；**对手血量 <25% 时 ×2**（补刀） |

再叠三条修正，与玩家完全同源：**克他 ×2、被他克 ×0.5、相生连击 ×1.4、刚用过的式子按后继无力打折**。
所以敌人也会自己换招、也会挑属性——它玩的是和你一样的游戏。

**性格（`AI_MOODS`）**——同一份牌组，靠六个倾向系数打出不同的人：

```
妖兽  凶 1.5 / 疗 0.3 / 守 0.4 / 控 0.6   只知道扑上去咬
魔修  凶 1.3 / 毒 1.4 / 疗 0.7 / 守 0.5   凶悍、爱下毒、不惜命
天骄  凶 1.0 / 疗 1.2 / 守 1.2 / 控 1.3   会留手、会控场、会先叠增益再打
心魔  用你自己的牌组与层数            「这些年你走的路，我都在。」
```

**家底（`KIND_GEAR`）**——数据里每个 NPC 都带武器/衣甲/戒指三件装备；
玩家这边法宝＋功法＋阵法叠起来轻松 ×2，不给敌人配家当，同境界就成了单方面碾压。
家底随境界铺开（炼气期的散修跟你一样穷，元婴之后才一身法宝）：

| | 妖兽 | 同门 | 修士 | 魔修 | 天骄 |
| --- | --- | --- | --- | --- | --- |
| 攻防倍率 | 1.00 | 1.60 | 1.75 | 1.82 | **2.25** |

于是难度阶梯自然成立。实测（化神期、装备齐全的玩家，**灵根写死**、每档 240 场 × 10 个种子）：

```
妖兽 100%  >  散修 90.5%  >  天骄 52.0%  ｜  越一个大境界 8.0%
标准差       ±1.8%          ±3.5%          ±1.9%
```

> 测胜率必须先把创角方差摁住：`createPlayer` 会随机摇灵根，而灵根决定主属性、亲和乘区与整副牌组。
> 不写死灵根时，同一份代码换个种子，散修胜率能从 67% 跳到 98%（跨种子标准差 10%，
> 远大于 240 场采样本身的 2%）——那测的是运气，不是战斗系统。

妖兽是稳妥的练级对象，散修有来有回，**天骄才是真正势均力敌的对手**——擂台与大比的分量由此而来。
反过来说，**不配家底的修士打不过同境界带装备的对手**：这是数值层的明确设定，不是 bug。

### 5.4 状态与层数

`Buff { kind, value, turns, stacks }`，回合结束统一结算：灼蚀（多层持续伤害）、生机（持续回血）、
易伤、减伤、反伤、身法、定身。护罩是独立于气血的吸收池，先破罩再掉血。

### 5.5 先手、闪避与逃跑

- 闪避 = `(遁速差 × 3 + 身法加成)`，上限 35%。
- 逃跑改**遁速检定**：`成功率 = clamp(0.5 + 遁速差×0.08, 0.15, 0.95)`；遁速远超对方时文案也不同（「化作一道遁光破空而去」）。失败则被追上多挨一记。

## 6. 渡劫：两场真战斗

`ascend()` 由 `chance(0.7)` 改为：

1. **心魔劫**——对手是「心魔 · 你自己」，属性镜像（0.9 倍），`noEscape + noItems`（丹药法宝皆是虚妄）。
   开场按**心境档位**给一层护罩（每档 8% 气血）：一辈子的心境修养，在这里第一次有硬用途。
   剧情 flag「佛魔一念」可直接跳过此劫。败则神魂受创，雷劫带着 55% 气血上场且护罩减半。

## 8.5 旁门收益：一切按「闭关一年」计价

论道 / 双修这类「不闭关也能涨修为」的渠道，收益一律写成**闭关一年的百分比**，
而不是一个常数。否则不置办洞府反倒划算——旧版白身双修每年拿到闭关的 4.2 倍，
「找洞府 / 抢灵脉」那条主轴就被架空了。

| | 修为 | 心境 |
| --- | --- | --- |
| 论道 | `闭关一年 × (0.4 + 0.6×她高出的大境界数) × 衰减` | `⌊3 × 她高出的大境界数 × 衰减⌋` |
| 双修 | `闭关一年 × (0.8 + 0.6×同上) × (1+双修宗门加成) × 衰减` | `⌊2 × 衰减⌋` |

**授业衰减** `1/(1+n)`：n 是自她上次**跨大境界**以来你与她论道/双修的次数。

- 她能教你的东西本来就是有限的：讲过一遍的道理，再讲十遍还是那一遍。
- 她高你两阶时**头一回**论道抵 1.6 年闭关、双修（合欢）抵 3 年——**难得，所以贵**；
  连刷十次的累计只有十年闭关的 0.47 倍，**刷她永远不如闭关**。
- **心境只从「在你之上的人」身上得**：她与你同阶或不如你，论道是切磋，不是受教。
  旧版论道恒 +3 心境、无冷却无衰减，34 次（34 年，五百年寿元的零头）即可刷满 100——
  而心境一路通到渡劫心魔劫的护罩（每档 8% 气血）与金丹品质。
- 想再有所得，要么**等她自己突破**（跨大境界即清零，把「等她成长」做成正向玩法），
  要么去认识别的人。

> 反刷这套工具（阈值门槛 + 收益随档位衰减到 0 + 冷却 + 一次性标记 + 心境几何阈值）
> 借鉴自参考数据的 `NPCxiaoxichufa`（`HaoGanDu > 100`、`HaoGanDuChange: 1→1→0`、
> `Rate: 20`、`IsOnly: 1`）与 `xinjin`（心境阈值 0/50/200/500/1000/2000 几何递增）。
> 本作沿用「收益递减」的结构，心境刻度仍保持 0~100，改由收益侧衰减实现等价效果。

## 10. 扩展指南

**加一式神通**（`content/spells.ts`）：

```ts
青冥指: S('青冥指', '木', 2, 3,
  [{ kind: 'dmg', value: 78 }, { kind: 'vuln', value: 20, turns: 2 }],
  '78% 伤害，两回合内敌方受伤 +20%',
  '你伸出一根手指。他退了半步——退完才想明白自己为什么要退。',
  { price: 900 }),
```

`price` 缺省＝不售（只能靠功法/机缘/剧情）；`sect` 标了就只在该宗法堂兑换。
测试会检查：`flavor` ≥10 字、`desc` 非空、`effects` 非空、`cost` 在 0~6、`tier` 合法、每系都有货。

**加一件法宝**：给 `tier`（缴获比高低用它）与 `atkPct/defPct`，别再写定值。

**加一条元婴异象 / 入道流派**：补 `YUANYING_VISIONS` / `DAO_PATHS`，战斗侧在 `combat.ts` 的 `tickEnd()` 与 `castSpell()` 里各有一处开关。

**调平衡**：先动 `BASE_STATS`（五个数）与 `PUNCH_COEF`，再动 `REALM_STEP/STAGE_STEP`。
`npm test` 固定随机种子（`FANGU_SEED` 可覆盖，`=random` 则真随机）——
胜率蒙特卡洛、渡劫存活这类断言本质是在采样一个分布，不定种子就会偶发假红，
同一份代码两遍绿一遍红，久而久之没人再看失败信息。
断言区间按「跨十个种子的实测均值 ± 3 个标准差」取，改完平衡记得重跑多个种子。

## 12. 后续方向

- 连战之间的灵气不延续（气血延续了），大比三轮的资源规划还可以更紧;
- 敌人还不会用丹药与符箓，也不会逃跑（`escape` 在它的牌组里被过滤掉了）;
- AI 权重表按「效果意图」推断，还不能像参考数据那样为**具体某一式**写专属条件;
- 神通「组合技」目前只有相生连击一种，可以再加「特定两式接续触发额外效果」;
- 洞府还只有一个数值维度，可以加「洞府带阵法位 / 灵田 / 护山禁制」;
- **渡劫的资源模型撑不住「备足才过」这句话**（已知缺口，待定）：
  九道雷总伤 113,088，满血 + 战前护罩 106,680——本是「差一口气，逼你在场上再想办法」的精准配平；
  但一式满级疗伤当场回 10,542，九个回合里放几次都行，于是**临场续航的量级（约 500% 气血）
  彻底压过了备战带来的量级（约 40% 气血）**。实测结果是断崖而非梯度：
  雷威 ×0.7~×3 时「备足的」与「仓促的」都是 20/20 全过，×5 时又都是 0/20 全灭，
  中间根本没有「备足才过」那一段。要让「两百年的积累在这里兑现」重新成立，
  得改的是资源模型而不是雷威系数——例如天劫压制临场续航（`sustainPct` 规则开关）、
  或雷劫改为每回合扣固定比例气血（让百分比疗伤失去杠杆）。
